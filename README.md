# Painel de Ruptura e Produção

Painel de ruptura de estoque por franquia e das entradas de produção da semana.

- **Abrir:** `index.html` (ou pelo link do GitHub Pages).
- **Acesso:** tela de login. Todo o conteúdo do painel fica criptografado dentro do arquivo (AES-256-GCM, chave derivada da senha com PBKDF2-SHA256) e só abre com um usuário válido.
- **Usuários:** um administrador cadastra ou remove usuários pelo botão "Usuários" dentro do painel e salva um arquivo novo. Para publicar a mudança, substitua o `index.html` deste repositório pelo arquivo salvo.
- **Dados atuais:** relatório "Estoque abaixo de 30 dias" de 25/09/2026 e entradas de produção de 13/09 a 19/09.
